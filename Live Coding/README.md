# 💻 Live Coding — Pemrograman Dasar TIF-H

Folder ini berisi dokumentasi **Live Coding Praktikum Pemrograman Dasar TIF-H**.

Live Coding dilaksanakan setelah mahasiswa menyelesaikan **dua bab materi**.

Bab 0 merupakan materi pengantar dan tidak termasuk dalam siklus Live Coding.

---

## Pola Live Coding

```text
Bab 1
   ↓
Bab 2
   ↓
Live Coding 01

Bab 3
   ↓
Bab 4
   ↓
Live Coding 02

Bab 5
   ↓
Bab 6
   ↓
Live Coding 03
```

Live Coding digunakan untuk mengevaluasi pemahaman mahasiswa terhadap konsep yang telah dipelajari pada dua bab sebelumnya.

---

## Daftar Live Coding

| Live Coding | Materi yang Diujikan | Status |
|:---:|---|:---:|
| **LC-01** | Bab 1 — Input, Output, dan Proses + Bab 2 — Seleksi Kondisi | ⏳ |
| **LC-02** | Bab 3 — Pengulangan + Bab 4 — Larik (Array) | ⏳ |
| **LC-03** | Bab 5 — Method + Bab 6 — Class dan Object | ⏳ |

> ✅ Sudah dilaksanakan  
> ⏳ Belum dilaksanakan

---

# Mekanisme

Secara umum Live Coding menguji kemampuan mahasiswa dalam:

```text
Memahami masalah
       ↓
Menentukan Input
       ↓
Menyusun Logika
       ↓
Mengimplementasikan Program
       ↓
Menguji Output
```

Penilaian dapat dilakukan menggunakan test case yang telah disiapkan pada sistem praktikum.
