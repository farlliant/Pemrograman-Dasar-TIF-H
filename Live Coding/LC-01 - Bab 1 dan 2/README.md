# Live Coding 01 — Bab 1 dan Bab 2

Live Coding 01 digunakan untuk mengevaluasi pemahaman materi:

```text
Bab 1 — Program Input, Output, dan Proses
Bab 2 — Seleksi Kondisi
```

---

## Cakupan Materi

### Bab 1

```text
Input
Output
Variabel
Tipe Data
Scanner
Operator Aritmetika
```

### Bab 2

```text
Conditional Assignment
If-Else
Nested If
Switch-Case
Operator Perbandingan
Operator Logika
```

---

## Kompetensi yang Diuji

Mahasiswa diharapkan mampu:

- menerima input dari pengguna;
- menyimpan data menggunakan variabel dan tipe data yang sesuai;
- melakukan proses perhitungan;
- menggunakan operator;
- menentukan kondisi menggunakan `if-else`;
- menggunakan `switch-case` apabila diperlukan;
- menghasilkan output sesuai spesifikasi soal.
