# UAP — Ujian Akhir Praktikum

Ujian Akhir Praktikum merupakan evaluasi akhir Praktikum Pemrograman Dasar.

UAP dilaksanakan dalam bentuk **Live Coding**.

---

## Cakupan

Cakupan materi akan mengikuti ketentuan pelaksanaan UAP dan materi yang telah dipelajari selama praktikum.

---

## Mekanisme

Mahasiswa diberikan permasalahan pemrograman yang harus diselesaikan menggunakan konsep yang telah dipelajari.

Evaluasi dapat meliputi:

```text
Problem Solving
Algoritma
Input dan Output
Control Flow
Pengulangan
Array
Method
Class dan Object
```

---

## Soal

Soal UAP belum dipublikasikan.

---

## Penyelesaian

Penyelesaian akan ditambahkan setelah ujian apabila diperbolehkan untuk dipublikasikan.
