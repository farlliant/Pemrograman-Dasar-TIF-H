# 📝 Ujian Praktikum — Pemrograman Dasar TIF-H

Folder ini digunakan untuk dokumentasi evaluasi utama pada Praktikum Pemrograman Dasar.

Evaluasi terdiri dari:

```text
UTP — Ujian Tengah Praktikum
UAP — Ujian Akhir Praktikum
```

Kedua ujian dilaksanakan dalam bentuk **Live Coding**.

---

# Ujian Tengah Praktikum

**Ujian Tengah Praktikum (UTP)** digunakan untuk mengevaluasi pemahaman mahasiswa terhadap materi yang telah dipelajari hingga pertengahan kegiatan praktikum.

Format evaluasi:

```text
Problem
   ↓
Analisis
   ↓
Implementasi Program
   ↓
Compile
   ↓
Test Case
   ↓
Penilaian
```

Detail cakupan materi mengikuti materi yang telah selesai sebelum pelaksanaan UTP.

---

# Ujian Akhir Praktikum

**Ujian Akhir Praktikum (UAP)** merupakan evaluasi akhir Praktikum Pemrograman Dasar.

UAP dilaksanakan dalam bentuk Live Coding dan dapat menguji kemampuan mahasiswa dalam menggabungkan beberapa konsep yang telah dipelajari.

---

# Struktur

```text
Ujian Praktikum/
├── README.md
│
├── UTP - Ujian Tengah Praktikum/
│   └── README.md
│
└── UAP - Ujian Akhir Praktikum/
    └── README.md
```

Soal, test case internal, dan penyelesaian yang belum boleh dipublikasikan tidak ditempatkan pada repository public.

---

# Prinsip Evaluasi

Evaluasi berfokus pada:

```text
Pemahaman Masalah
       ↓
Perancangan Logika
       ↓
Implementasi
       ↓
Ketepatan Output
       ↓
Penanganan Kasus Uji
```
